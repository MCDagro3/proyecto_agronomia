02 · Agricultura DGSIAP

Un archivo anual, una ruta predecible

La URL se construye con el año y cada respuesta se conserva como agricola_{año}.csv. Si el archivo existe, la función continúa sin descargarlo otra vez.

datasets/agricultura.py
for anio in ANIOS:
    ruta = directorio / f"agricola_{anio}.csv"

    if ruta.exists():
        archivos.append(ruta)
        continue

    respuesta = requests.get(
        URL.format(anio=anio), timeout=120
    )
    respuesta.raise_for_status()
    ruta.write_bytes(respuesta.content)

08 · Diseñado para fallar bien

Internet puede fallar; el proceso no debe empezar de cero

La adquisición separa errores recuperables, archivos completos y resultados validados.

01Existe → reutilizar
02Timeout → reintentar
03.tmp / .part → escritura atómica
04HTTP inválido → detener
05Clave duplicada → rechazar
06Días incompletos → nulo explícito
Idempotencia + caché + validaciones = reproducibilidad operativa
