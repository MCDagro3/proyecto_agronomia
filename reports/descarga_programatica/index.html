01 · Una sola fuente de verdad

Las rutas no viven dispersas en el código

config.py concentra periodos, URLs, parámetros y directorios. Cada módulo recibe rutas por defecto, pero permite sustituirlas en pruebas o ejecuciones especiales.

RAWdata/raw/{fuente}Respuesta original, ZIP, JSON o TIFF
INTERIMdata/interim/{fuente}Geometrías y resultados intermedios
PROCESSEDdata/processed/{fuente}Tablas listas para integrar
REFERENCESreferences/Diccionarios oficiales
config.py→datasets/*.py→resguardo en raw/
02 · DGSIAP · Agricultura

Un archivo anual, una ruta predecible

La URL se construye con el año y cada respuesta se conserva como agricola_{año}.csv. Si el archivo existe, la función continúa sin descargarlo otra vez.

05 · NASA POWER

06 · Diseñado para fallar bien

Internet puede fallar; el proceso no debe empezar de cero

La adquisición separa errores recuperables, archivos completos y resultados validados.

01Existe → reutilizar
02Timeout → reintentar
03.tmp / .part → escritura atómica
04HTTP inválido → detener
05Streaming → progreso visible
06Mismo archivo → no duplicar
Idempotencia + caché + escritura atómica = reproducibilidad operativa
07 · Ejecución desde la CLI

Los módulos concentran toda la lógica

Cada fuente se descarga con una función de datasets/*.py; la CLI las invoca directamente y devuelve las rutas de los archivos resguardados.
