# Storytelling interactivo

La presentación es un sitio HTML estático y no requiere un servidor ni una
instalación adicional.

## Uso

1. Abrir `index.html` en Chrome, Edge o Firefox.
2. Usar las flechas del teclado, Page Up/Page Down o la rueda para navegar.
3. Activar **Pantalla completa** antes de exponer.

Los recursos visuales se cargan desde `reports/figures/`. Si se mueve la
carpeta `storytelling`, debe conservarse su posición relativa respecto a esa
carpeta.
